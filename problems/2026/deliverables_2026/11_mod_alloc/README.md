## Задание

1. Разработать модуль ядра Linux, выделяющий заданный объем памяти с помощью kmalloc и vmalloc по команде, получаемой из user-space через символьное устройство
2. Используя модуль, выяснить, какой максимальный объем можно выделить через kmalloc/vmalloc

## Выполнено

- Модуль ядра с символьным устройством `/dev/mod_alloc`: `mod_alloc.c`.
- `ioctl`-интерфейс для:
  - выделения через `kmalloc` и `vmalloc`,
  - освобождения,
  - чтения текущей статистики.
- User-space утилита бинарного поиска максимального размера: `test_alloc.c`.

## Сборка и запуск

- Собрать модуль: `make`.
- Собрать user-space тест: `make test`.
- Загрузить модуль (`insmod mod_alloc.ko`) и запустить `./test_alloc`.
