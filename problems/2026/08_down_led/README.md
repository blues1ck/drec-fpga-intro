## Задание

* Установить Vivado 2025.1
* Запустить на плате счетчик с выводом на LED
* Написать счетчик обратного счета с выводом на LED и запустить его на плате 

## Выполнено

- Добавлен RTL-счетчик обратного счета: `src/cnt.sv`.
- Добавлен верхний модуль для вывода на 4 LED: `src/fpga_top.v`.
- Добавлен простой testbench: `src/cnt_tb.sv`.
- Добавлены `Makefile` и `project.tcl` для сборки проекта Vivado.

## Запуск

- Локальная проверка: `make verilator`.
- Создание Vivado-проекта: `make project`.
