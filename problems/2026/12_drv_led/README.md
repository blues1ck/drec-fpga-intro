## Задание

1. На основе модуля `axil2reg` сделать свой аналог IP-блока AXI GPIO, предоставляющий доступ на чтение и запись к 4-битному регистру, управляющему светодиодами 
2. Разработать драйвер для Linux, позволяющий user-space программам через файловые операции над символьным устройством в `/dev` управлять светодиодами на плате

## Выполнено

- Реализован Linux platform-драйвер для MMIO LED IP: `led_drv.c`.
- Драйвер публикует символьное устройство `/dev/led_drv`.
- Поддержаны операции:
  - `read`/`write` для чтения и установки 4-битного значения,
  - `ioctl` (`LEDDRV_SET`, `LEDDRV_GET`) через `cmds.h`.
- Добавлена user-space проверка: `test_led.c`.

## Сборка и запуск

- Собрать модуль: `make`.
- Собрать тест: `make test`.
- После загрузки драйвера (`insmod led_drv.ko`) запустить `./test_led`.

## Примечание по железу

- RTL AXI-Lite LED IP на `axil2reg` находится в задаче `09_ps7_axil_led`.
- Для автоматического биндинга в DT используйте `compatible = "drec-fpga-intro,axil-led"`.
